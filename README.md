# 국방기술 아틀라스

대한민국 국방기술기획서(’17~’26 발간 9개 판)와 관련 기획·조사서를 구조화해 **국방기술 현황, 연도·기술·체계별 분포, 과제 계보, 예산, 중복성 점검, 기술 연계 온톨로지, 향후 방향**을 보여주는 정적 웹사이트입니다. 서버 없이 GitHub Pages에서 그대로 동작합니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**
2. Branch: `main`, 폴더: `/ (root)` 선택 후 저장
3. `https://<계정>.github.io/Technology/` 에서 확인

로컬에서 볼 때는 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속(파일을 직접 열면 data 로딩이 막힙니다).

## 데이터 관리(DB)

사이트의 **데이터 관리** 메뉴에서 데이터를 직접 고칠 수 있습니다. 수정 내용은 기획서에서 추출한 원본(`data/*.json`)을 덮어쓰지 않고 `data/db/`에 따로 쌓이므로, PDF 파이프라인을 다시 돌려도 사라지지 않습니다.

| 파일 | 내용 |
|---|---|
| `data/db/planned.json` | 우리 계획 과제(상태·담당·예산·메모, 저장 시점의 중복 점검 결과 포함) |
| `data/db/overrides.json` | 기존 레코드 수정분·삭제 표시(대상별 ID 기준) |
| `data/db/added.json` | 직접 추가한 과제·소요·민간기술·소재부품 |
| `data/db/changelog.json` | 변경 이력(일시·대상·ID·작업) |

저장 흐름
1. 화면에서 추가·수정·삭제 → 이 브라우저에 임시 저장(‘저장 안 된 변경 N건’ 표시)
2. **GitHub 저장 설정**에 토큰 입력 → **GitHub에 저장**을 누르면 위 4개 파일이 저장소에 커밋되고, 1~2분 뒤 모든 사용자 화면에 반영
3. 토큰 만들기: GitHub → Settings → Developer settings → Personal access tokens → *Fine-grained tokens* → 이 저장소만 선택, **Repository permissions → Contents: Read and write**
4. 토큰 없이 쓸 때는 **DB 내보내기**로 JSON을 받아 다른 사람에게 전달하고, 받은 쪽에서 **DB 가져오기**로 적용할 수 있습니다.

참고: 판별 집계·예산 추세·개념 추세 같은 사전 계산 차트는 파이프라인을 다시 실행해야 수정분이 반영됩니다. 과제 목록·상세·중복성 점검·체계별 열지도 등은 즉시 반영됩니다.

## 온톨로지 모델

```
기획서 판 ──수록──▶ 과제 ──적용──▶ 무기체계 분야(10)
                     │  ├─속함──▶ 기술분야(8대/6대)
                     │  ├─기여──▶ 국방전략기술 L1(30) ─▶ 분야(10)
                     │  ├─언급──▶ 기술개념(Concept) ◀─언급─ 기술개발소요 / 민간보유기술 / 소재·부품
                     │  └─유사──▶ 과제
국방전략기술 L1 ─구체화─▶ 세부기술 L2 ─▶ 구성기술 L3 ─▶ 기술개발소요
```
기술개념 사전은 `scripts/concepts.py`에서 수정·추가할 수 있습니다.

## 데이터 갱신 (새 기획서 반영)

필요: Python 3.10+, `poppler-utils`(pdftotext), `pip install pdfplumber scikit-learn numpy`

1. `pdfs/` 폴더를 만들고 원문을 다음 이름으로 넣습니다.
   `17-31_핵심기술기획서.pdf`, `18-32_…`, `19-33_…`, `21-35_국방기술기획서.pdf` … `26-40_국방기술기획서.pdf`, `26-30_소재부품기획서.pdf`
2. `bash scripts/run_all.sh`
3. 새 판(예: ’27~’41)은 `scripts/common.py`의 `DOCS`, `build_data.py`의 `EDITIONS`/`ED_LABEL`에 추가합니다.

## 한계

- 공개본(일반본)에 수록된 과제만 포함합니다. ’20~’34판은 자료가 없어 빠져 있습니다.
- ’17~’19판은 예산이 없고 ’19판은 기간 대신 단기/중기만 표기되어 있습니다.
- ’25판 이전 과제의 국방전략기술 분야는 텍스트 분류 추정치입니다(교차검증 정확도 약 64%). 화면에서 점선 태그와 `*`로 구분합니다.
- 연도별 투자는 총사업비를 사업기간에 균등 배분한 추정치입니다.
- 중복성 점수는 문자 n-gram 유사도이므로, 최종 판단은 연구항목·목표성능 비교로 하세요.
